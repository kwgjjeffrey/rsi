# 适配器验证

由 Agent 根据真实样本补充断言：至少覆盖一种有效输入、一种缺失或异常输入，以及保留 task_input/case_id 和未知字段。API 接入另验证分页、去重与脱敏；Replay 验证新 session、实际 Skill 加载、结束和超时；results 验证原始轨迹未丢失、错误未转为成功。

没有实际执行的集成测试要写明未验证，不得用协议校验或人工合成事件证明真实 Harness 可用。测试样本不得进入目标 Skill 发行包。

验证脚本本身可以作为项目脚手架保留；测试样本、截图、临时请求、运行输出和未决定是否收录的中间数据统一放 RSI 工作区 `.trial/`，不得放入真实项目的 `.data/`。只有正式收录的问题集和迭代 Replay 证据进入 `.data/`。
