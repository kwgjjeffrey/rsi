# 归一化实现约束

复用根开发约束。通用工具不包含项目业务取数、CDP 选择器、App Server RPC 名或作者机器路径。项目适配器从分发模板生成到外部数据根；初始化不能覆盖既有脚本。协议变更需要版本与兼容测试，入口/依赖变化不得复用旧合同回执。保持旧 replay.command 配置兼容。

测试至少覆盖：源格式不支持、原标注/未知扩展保留、同构输入、评价上下文不进入重放、结果适配器不能注入 gold、超时、越界、协议与集成状态区分。不得用人工事件测试宣称真实 Harness 已验证。

验证脚本本身可以作为项目脚手架保留；测试样本、截图、临时请求、运行输出和未决定是否收录的中间数据统一放 RSI 工作区 `.trial/`，不得放入真实项目的 `.data/`。只有正式收录的问题集和迭代 Replay 证据进入 `.data/`。
